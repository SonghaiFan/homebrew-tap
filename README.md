# Homebrew Tap for SonghaiFan

Official Homebrew tap for LeftOpen and related utilities.

## How to Install LeftOpen

```bash
brew install --cask SonghaiFan/tap/leftopen
```

Or add the tap first:

```bash
brew tap SonghaiFan/tap
brew install --cask leftopen
```

## Updating

```bash
brew upgrade --cask leftopen
```
